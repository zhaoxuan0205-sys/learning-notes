# Learning Notes

把散落的录音、转写和讲义，整理成方便复习、分享和持续积累的学习笔记。

## 为什么需要它

参加完培训、听完演讲或播客，材料存下来了，整理却还没开始：逐字稿太长，自动摘要又可能漏掉关键概念、数字和案例。想回顾某个结论，还得重新翻找原文。

Learning Notes 为 AI 助手提供一套整理流程：先梳理知识结构，再核对关键内容，最后生成有来源、能继续更新的笔记。适合希望整理课程内容、分享给同伴，或逐步建立个人知识库的人。

## 你能得到什么

- **有脉络的正文：** 按概念、方法和案例组织，减少口语重复，保留理解所需的细节。
- **可回溯的重点：** 核对关键数字、案例归属和结论，保留原文入口，标记材料缺失与不确定处。
- **可复用的学习资产：** 提炼方法、积累待研究问题，多日课程持续追加，保留你的手工修改。
- **指定位置的成稿：** 从本地文件、网页或 App 读取材料，整理后写入约定文件或在线文档，并返回成果入口。

有现成文字时优先读文字，音频用于补缺和校准，视频画面按需读取。现场可以先保留重点，课后再结合完整材料统一整理。

## 怎么用

1. **启用 Skill**

   在仓库页面选择 **Code → Download ZIP**，解压后将文件夹改名为 `learning-notes`，安装到所用 AI 工具的 Skills 目录；也可以让助手读取文件夹中的 `SKILL.md`。保留 `references` 等子目录。不同工具的安装入口可能不同。

2. **告诉助手：材料在哪里**

   提供本地文件夹路径、网页链接或 App 中的记录位置。支持文字、讲义、音频和视频；已有转写时优先读文字。课程进行中可先记录重点，结束后统一校准。

3. **告诉助手：笔记放在哪里**

   说明保存到本地、飞书、腾讯文档或其他位置，以及新建还是追加。更新已有文档时，提供链接和要修改的章节；有详细度、格式等要求可一并说明。

4. **由助手完成整理与交付**

   信息齐全后，助手读取、校准、排版、写入并核验，返回文档链接或文件路径。所用 AI 工具需具备相应访问能力；缺少登录或权限时会说明需要你完成的最小操作。

## 比如

你已把第二天的培训材料下载到桌面，想补充到飞书笔记，可以这样说：

```text
用 learning-notes 帮我整理第二天的培训笔记。
材料位置：桌面“课程材料”文件夹，里面是第二天的转写稿和讲义。
成果位置：飞书文档【粘贴你的文档链接】，追加到“第二天”章节，保留第一天的内容。
保留概念、案例、关键数字与原文入口，正文不显示时间戳，完成后给我文档链接。
```

把文件夹、链接和章节换成自己的即可。没有现成文档时，将成果位置改为“在飞书中新建一份学习笔记”。

具体整理规则见 [SKILL.md](SKILL.md)。反馈问题时，请说明材料类型、目标位置和遇到的具体情况。
