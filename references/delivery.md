# 链路执行

## 定位与能力检查

用一行记录约定：`输入位置与范围 → 整理要求 → 输出位置、新建或更新范围`。只补问未知项，已打开的页面或已提供的路径可以直接检查。

优先使用当前可用连接器、文件工具或 API；能力不足时使用浏览器或 App 控制。先做最小读取，确认选对材料和目标、具备编辑权限，再处理长内容。尚未登录、缺权限或存在同名目标时定位具体阻点，不将“已打开”当作“可读取、可编辑”。

| 位置 | 助手执行 |
|---|---|
| 本地文件或文件夹 | 检查给定路径，在用户指定范围内列文件，关联摘要、转写与音视频；有可读文字直接处理 |
| 网页或在线笔记 | 打开指定链接或当前页面，核对记录标题，读摘要与全文；必要时自行导出或下载可用文字 |
| App | 定位指定记录，读取文字或使用已有导出功能；App不可访问时检查同一服务可用网页 |
| 本地输出 | 按约定目录和格式生成文件，检查文件存在且内容完整，返回可打开路径 |
| 在线文档 | 在约定位置新建文档，或读取指定文档后写入目标区块；检查格式、正文与保存状态，返回真实链接 |

平台未指定具体新建目录且存在用户默认空间时可沿用；存在多个无法区分的目标或可能覆盖原内容时才补问。用户明确指定的读取与写入属于同一任务，常规步骤连续完成；仅在缺少用户才能提供的登录、权限或必要选择时请求最小介入。

## 写入与恢复

1. 完成草稿和校准后再写入；长文分批写，记录已完成区块。
2. 更新前回读最新版本，保留人工修改。写入中断或响应不明时，先查实际内容，再补写缺失部分，避免重复创建或追加。
3. 回读目标内容，对照预期章节、关键指标、来源和占位符；检查实际排版及保存成功。只有标题或空壳文档不算完成。
4. 输出链接或文件路径，并说明实际写入范围和剩余缺项。不要以对话中的“完成”代替保存证据。

本地原文路径只能帮助本人定位。若用户要求共享原文回溯，在已授权范围内上传原文或创建来源文档，并使用真实链接；未授权分发的材料保留脱敏名称及访问限制，不擅自公开或扩大权限。

## 卡点处理

先尝试当前可用的替代读取或写入方式，再请求用户操作。需要登录、验证码或权限时说明具体页面及最小动作；完成后从检查点继续。没有可用工具时交付草稿并明确标注“目标尚未写入”，不得声称已完成在线交付。
