# 材料处理

## 输入选择

| 当前材料 | 处理方式 |
|---|---|
| 摘要与完整文字 | 摘要建地图，原文补全并核对；两者不算独立证据 |
| 仅文字 | 按内容分段读取，不要求额外音视频 |
| 文字与音频 | 文字完成主体工作，只回听术语、数字、否定词、缺句和案例切换 |
| 仅音频 | 有可用能力时转写；涉及新增付费或向新服务上传时按用户授权处理 |
| 视频 | 先用已有字幕或音轨；图表、板书、演示和画面指代缺失时定向读画面 |
| 网页 | 读取可用文字并记录具体项目标题、地址和范围，确认正文未被分页或折叠截断 |

来源可信度按问题判断：音频确认实际措辞，讲义确认框架与图表，转写便于检索，摘要提供线索。不同来源冲突时保留冲突及处理依据。

## 覆盖与复用

长材料按主题或连续范围切分；每段保留少量上下文，核对首尾衔接。每读完一段更新一行：

`来源 ID｜角色及版本｜已读范围｜主要主题｜未读或缺失范围`

关键证据另记 `内容｜来源 ID＋段落或时间｜状态`。旧稿只能提供候选线索，最终稿用于继承已确认的修正和风格。不要用旧稿验证旧稿。

在索引基础上合并跨段主题，补全后置定义、案例和限定条件；修订时优先查已有索引，避免从头重读。完整性以覆盖范围判断，不能只看是否找到了预想关键词。

## 现场与课后衔接

现场阶段可由用户或工具留下重点，不要求本 Skill 实时运行。若当前环境能够持续读取新增文字：

1. 保存来源与读取位置，维护主题、概念、案例、数字、疑点及用户标记。
2. 按新增内容更新；若源文字修订旧句，以稳定片段 ID 或位置替换旧记录，避免重复累计。
3. 主题结束时保存检查点。临时转写和阶段性摘要标为待校准，不提前定论。
4. 用户叫停时保存进度并结束监听；明确课程结束后转入课后整理。短暂断流不等于课程结束；无法继续读取时报告覆盖截止位置。
5. 课后以完整文字补齐未覆盖范围，处理疑点和重要修正，再统一成稿。只有来源版本改变或存在缺口时才重读已处理范围。
